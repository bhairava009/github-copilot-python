# GitHub Copilot Instructions

## Coding Standards
- Follow Python PEP8.
- Keep functions small and reusable.
- Use meaningful variable names.
- Preserve existing functionality.
- Write modular code.
- Handle errors gracefully.
- Add comments where helpful.

## Project Goals
- Build a Flask Sudoku game.
- Add Easy, Medium, and Hard difficulty levels.
- Ensure puzzles have exactly one unique solution.
- Add a timer.
- Add Hint and Check buttons.
- Save the Top 10 scores in local storage.
- Support dark mode.
- Make the layout responsive for desktop and mobile.
